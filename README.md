# Tic-tac-toe

Play a two-player game at [GitHub Pages](https://gh-900-orgg.github.io/html-tic-tac-toe-game/), or open `index.html` in a browser. Players take turns as X and O; the first to get three in a row wins. Use **Restart game** to play again.

## Publishing

In the repository's **Settings → Pages**, select **GitHub Actions** as the build and deployment source. The Pages workflow deploys the site when changes are pushed to `main`, and can also be run manually from the Actions tab.
